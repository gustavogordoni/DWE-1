Praticando 1 - Tabelas com dados reais

Praticando 1 - Nessa atividade você vai praticar tags como <table>, <caption> e <th scope = "col"> para estruturar dados de forma semântica.

Praticando 2 - Aqui você vai praticar os atributos <td colspan = "4"> e <td rowspan = "4">, usados para mesclar céluas e criar tabelas mais complexas.

Praticando 3 - Receita de bolo com listas
