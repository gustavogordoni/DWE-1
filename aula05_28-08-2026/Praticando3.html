SEÇÃO 3 - Por que entidades existem de verdade

Além dos símbolos "bonitinhos", entidades resolvem um problema real: como mostrar um sinal de menor (&lt;) ou maior (&gt;) na tela sem o navegador achar que é o início de uma tag?

Se eu quiser que a tag <p> apareça como texto normal (sem virar um parágrafo de verdade), preciso escrever &lt;p&gt; no código-fonte.

O mesmo vale para o "E comercial" (&): quando eu quero mostrá-lo literalmente, preciso escrever &amp;.

(Nota: Repare que a tag <code> foi usada aqui porque ela indica que aquele trecho é código — e o navegador já mostra esse texto com uma fonte diferente por padrão, sem eu precisar definir nada com CSS.)

Element Inline vs. Block

Alguns elementos HTML ficam na mesma linha que o conteúdo ao redor (inline); outros sempre começam em uma linha nova (block). Compare:

Inline

<a> <strong> <em> <mark> <code> H2O (<sub>) m2 (<sup>)

Repare: todos os exemplos acima ficam lado a lado, na mesma linha.

Block

<div> - um container genérico.
<p> - um parágrafo.
<h1> a <h6> - títulos.
<blockquote> - uma citação.
<section> - uma seção (como esta própria página usa!)

Repare: cada exemplo acima começa em uma linha própria, mesmo sendo um texto curto.
