Como criar um mod

Criar um mod é mais acessível do que parece. Aqui está o caminho geral, do zero até a publicação.

Etapas

  1. Entenda o que você quer criar. Inicie criando ajustes simples ao invés de um mod complexo.
  2. Prepare o ambiente. Instale um editor de código (como Visual Studio) e o SDK do .NET.
  3. Instale um carregador de mods. PEAK utiliza-se do BepInEx, que "injeta" o código do mod no jogo.
  4. Escreva o código. Muitos mods usam a bibliotecas para alterar o comportamento de funções do jogo sem modificar os arquivos originais.
  5. Compile e teste. Gere o arquivo .dll, coloque na pasta de plugins do jogo e teste várias vezes.
  6. Empacote. Para a Thunderstore, o pacote em .zip deve conter o .dll, um manifest.json (nome, versão, descrição, dependências), um README.md e um icon.png de 256x256 pixels.
  7. Publique. Envie o pacote para a plataforma e compartilhe com a comunidade.

Ferramentas úteis

Ferramenta Para que serve
Visual Studio Escrever o código
BepInEx Carregar o mod no jogo
Thunderstore Publicar e distribuir
